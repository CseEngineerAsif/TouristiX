## 📊 Executive Summary

**TouristiX** is a comprehensive full-stack web application designed to revolutionize tourism in Bangladesh. The platform serves as a centralized hub connecting travelers with hotels, guides, transport services, and curated travel packages. With an intuitive interface and robust admin management, TouristiX ensures seamless booking experiences for tourists while providing administrators complete control over content and operations.

**Target Audience:**
- Domestic & international tourists visiting Bangladesh
- Tour guides and hospitality service providers
- Hotel and transport operators
- Tourism administrators

## 🛠️ Technology Stack

### Backend
- **Framework:** Node.js + Express.js (v18+)
- **Runtime:** JavaScript (ES6+)
- **Authentication:** Express-Session + bcryptjs
- **Password Security:** bcryptjs with salt rounds 10

### Database
- **System:** SQLite3 (Lightweight, File-based)
- **Auto-scaling:** Supports up to 100K+ records
- **Location:** `database.sqlite` (auto-created)

### Frontend
- **Template Engine:** EJS (Embedded JavaScript)
- **Styling:** Custom CSS3 + CSS Variables
- **Icons:** Font Awesome 6.4.0
- **Responsive:** Mobile-first approach

### Middleware & Libraries
- **File Upload:** Multer (v1.4.5)
- **Session Management:** express-session
- **Flash Messages:** connect-flash
- **Method Override:** Support for PUT/DELETE
- **Environment Config:** dotenv

### Development
- **Dev Server:** Nodemon (live reload)
- **Package Manager:** npm
- **Version Manager:** Node v16+

## 📋 Database Schema

### Core Tables

#### **Users Table**
```sql
- id (PRIMARY KEY)
- name, email (UNIQUE), password (hashed)
- phone, avatar, role (user/admin)
- wallet_balance (for bookings)
- created_at (TIMESTAMP)
```

#### **Tourist Spots Table**
```sql
- id (PRIMARY KEY)
- name, district, division, category
- description, image (file path)
- rating, total_reviews, entry_fee
- best_time, created_at
```

#### **Hotels Table**
```sql
- id (PRIMARY KEY)
- name, location, district
- price_per_night, amenities
- available_rooms, rating
```

#### **Transport Table**
```sql
- id (PRIMARY KEY)
- type (Bus/Train/Air/Launch)
- route_from, route_to
- price, departure_time, duration
- availability_count
```

#### **Guides Table**
```sql
- id (PRIMARY KEY)
- name, expertise, experience_years
- phone, location, rate_per_day
- verified_status, rating
```

#### **Bookings Table**
```sql
- id (PRIMARY KEY)
- user_id, service_type, service_id
- travel_date, departure_time
- amount, status (pending/confirmed/cancelled)
- created_at
```

#### **Packages Table**
```sql
- id (PRIMARY KEY)
- name, description, duration_days
- included_spots, hotel_reference
- guide_reference, transport_reference
- total_price, discount_percentage
```

#### **Reviews Table**
```sql
- id (PRIMARY KEY)
- user_id, spot_id, rating (1-5)
- comment, created_at
```

## 🚀 Installation & Setup

### Prerequisites
- Node.js v16 or higher
- npm (comes with Node.js)
- VS Code or any code editor
- Modern web browser

### Step-by-Step Installation

1. **Clone/Download Project**
   ```bash
   cd banglatour
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   Create `.env` file:
   ```env
   PORT=3000
   SESSION_SECRET=touristix-secret-2024
   NODE_ENV=development
   ```

4. **Start Server**
   ```bash
   npm start
   ```
   Or for development with auto-reload:
   ```bash
   npm run dev
   ```

5. **Access Application**
   - User Portal: http://localhost:3000
   - Admin Panel: http://localhost:3000/admin/dashboard
   - Register at: http://localhost:3000/auth/register
